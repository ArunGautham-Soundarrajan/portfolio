`proxy-server` is an experiment in building a reverse proxy in Go with caching layered into the request path. It sits in the space between backend infrastructure and systems programming, focusing on how requests are routed, cached, and served efficiently.

The project is useful as a practical exploration of HTTP fundamentals in Go: request forwarding, response handling, and the mechanics involved in reducing repeated upstream work through a cache-aware proxy layer.
