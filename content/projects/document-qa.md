`document_qa` is the backend for a document question-answering application. It fits squarely into retrieval and GenAI workflows, where documents are ingested and exposed through an interface that can answer user questions against the source material.

This project is especially aligned with my recent work in search and retrieval systems, since it reflects the backend concerns behind document-grounded AI: orchestration, retrieval, and serving answers through an application API.
